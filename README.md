# Sistemas Distribuidos

Este repositorio contiene proyectos de sistemas distribuidos utilizando **Go** y **ngrok** para exponer servicios locales a través de internet.

## Proyectos

### 1. Simple HTTP Server
Un servidor HTTP básico en Go que puede ser expuesto mediante ngrok.

### 2. Client-Server Communication
Ejemplo de comunicación cliente-servidor usando Go.

## Requisitos

- Go 1.16 o superior
- ngrok (para exponer servicios locales)

## Instalación de ngrok

1. Descarga ngrok desde [https://ngrok.com/download](https://ngrok.com/download)
2. Extrae el archivo y colócalo en tu PATH
3. (Opcional) Crea una cuenta en ngrok y autentica: `ngrok authtoken <tu-token>`

## Uso

Cada proyecto tiene su propio directorio con instrucciones específicas en su README.
